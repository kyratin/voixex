Voixex 0.8.0 reduces avoidable media processing and prevents stale audio/video from building up behind a slow connection.

- Ignore near-digital microphone silence while preserving quiet speech and a short speech tail.
- Compute each room's source sum once and share Opus encoding for identical listener mixes. New stream epochs and decoder warm-up preserve safe transitions; older clients keep their existing protocol.
- Prioritize voice and control messages over camera traffic, bound application and WebSocket worker queues, and discard expired audio and incomplete or outdated camera frames.
- Negotiate compatibility voice/camera demand to avoid redundant processing when WebRTC is ready, with leased state and automatic compatibility fallback.
- Adapt playback buffering to network jitter without changing the sample rate.
- Move password hashing to a bounded worker pool so login bursts do not block the API event loop.

Android APK, macOS Apple Silicon DMG, and Windows x64 installer are attached below. The server image is published separately to Docker Hub as `kyratinkokko/voixex:0.8.0` and `latest`, for both `linux/amd64` and `linux/arm64`.

Capacity still depends on active speakers, camera fan-out, network bandwidth, and server CPU. This release retains one media worker per server; it does not introduce distributed room sharding. Automated checks do not certify every physical Android device or Wi-Fi network.
