Voixex 0.8.5 adds a native Windows path for screen-share system audio.

- Windows uses a dedicated WASAPI process-loopback helper instead of Chromium screen-audio capture. It excludes the entire Voixex process tree, including Electron's audio service, to keep call playback out of the stream.
- Captured stereo audio is delivered to the existing LiveKit and MediaRecorder screen-share tracks. Stopping the stream, closing or navigating the capture window, and helper failures release the capture and audio resources.
- Native activation failures leave screen video available without falling back to audio that includes the call. Windows 10 2004+ is eligible for an activation attempt; physical Windows 10 21H2 audio capture and exclusion still need device verification.
- macOS retains its existing ScreenCaptureKit/Core Audio path and own-audio exclusion.

Windows x64 installer, macOS Apple Silicon DMG and Android APK are attached. The Windows installer bundles the native helper; no virtual audio driver is required.
