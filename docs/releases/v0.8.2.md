Voixex 0.8.2 restores active-speaker indication while cameras are enabled.

Camera participant tiles now show a voice-responsive green frame and speaking marker in both the main call view and the mini window. The indication follows local microphone levels and remote compatible/WebRTC voice levels, and clears on silence or mute. Avatar mode retains its voice rings.

Includes the 0.8.1 fix for voice transmission after silence and compatibility-stream pauses. Android APK, macOS Apple Silicon DMG and Windows x64 installer are attached.

The faulty 0.8.0 client release has been removed from GitHub. The server runtime is unchanged; Docker Hub server image 0.8.0 remains compatible.
