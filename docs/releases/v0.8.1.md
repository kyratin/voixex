Voixex 0.8.1 fixes a voice transmission regression in the browser/Android media engine after microphone silence or compatibility-stream suspension.

The Opus encoder may produce timestamps on its own continuous codec timeline. Version 0.8.0 matched those timestamps against packet frame numbers that jumped across pauses; after a gap, valid encoded speech could be discarded indefinitely. The newest participant's fresh encoder could still work while earlier participants became inaudible.

This patch matches ordered Opus output to captured-frame metadata independently of codec timestamps. It preserves packet deadlines and switches to compatible PCM if the encoder repeatedly misses its deadline or stops producing output. Room/connection changes close the old encoder so its delayed output cannot enter a new session.

Added real WebCodecs regression checks cover multiple participants, silence, stream-demand suspension/resumption and encoder stalls; server turn-taking checks include staggered joins, all speaker combinations and leave/rejoin.

Android APK, macOS Apple Silicon DMG and Windows x64 installer are attached. Update every affected client. The server image remains 0.8.0; no server runtime change is required for this client fix.
