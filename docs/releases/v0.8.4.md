Voixex 0.8.4 fixes self-speaking indication and intermittent black frames in the screen-share pop-out window, and improves screen-audio capture compatibility.

- Quiet microphone speech now activates the local frame using a threshold aligned with remote levels. Verified self legacy/SFU levels provide fallback indication; mute still clears it immediately.
- Pop-out video retains its live stream and cloned track across UI updates. Updates no longer stop and recreate the video source; closing the pop-out releases only its owned clone.
- The screen source selector now uses the application's capture handler. Electron's native picker shortcut bypassed the audio callback and could return video without stream sound.
- Updated Windows 10 2004+ systems can attempt isolated process-loopback audio instead of being rejected by the previous blanket build 20348 gate. Actual native activation and a live track confirming own-audio exclusion are still required; failures remain video only. Physical Windows 10 capture must be verified on the sender's device.

The production server was inspected without restarting the active stream: it had screen video but no published screen-audio track, despite permission to publish it. Server code and Docker image are unchanged.

Android APK, macOS Apple Silicon DMG and Windows x64 installer are attached.
